# Como Funciona o Algoritmo do Airbnb

> Resumo completo baseado na entrevista com Roberto Rizo Patron, diretor comercial do Airbnb para América do Sul.

# Visão Geral

O algoritmo do Airbnb tem um único objetivo:

## Gerar reservas.

Ele prioriza anúncios com maior chance de:
- receber cliques,
- converter reservas,
- entregar boa experiência,
- manter hóspedes satisfeitos.

O anfitrião fornece o imóvel.  
O algoritmo decide quem ganha visibilidade.

# Os 5 Pilares da Visibilidade

## 1. Disponibilidade de Calendário

Quanto mais flexível o calendário, melhor o posicionamento.

### O algoritmo favorece:
- calendário aberto por muitos meses;
- estadia mínima menor;
- menos restrições;
- disponibilidade ampla.

### Problema comum
Anfitriões que abrem apenas 2 ou 3 meses.

### Resultado esperado
Mais visibilidade e mais oportunidades de reserva.

## 2. Amenidades Certas

Não é sobre ter tudo.  
É sobre ter o que o público valoriza.

### Exemplos:
#### Executivo:
- internet rápida,
- mesa de trabalho,
- cafeteira,
- self check-in.

#### Família:
- cozinha completa,
- lavanderia,
- utensílios,
- segurança.

### Ideia principal
Entender:
> “Quem costuma reservar meu imóvel?”

## 3. Preço Competitivo

Preço competitivo NÃO significa:
- ser o mais barato.

O Airbnb compara:
- imóveis similares,
- mesma região,
- mesma categoria,
- mesma experiência.

### O algoritmo avalia:
- preço total,
- taxa de limpeza,
- descontos,
- qualidade geral.

## 4. Qualidade do Anúncio

O foco atual está no selo:

# Preferido dos Hóspedes

Mais importante que `Superhost`.

### O algoritmo analisa:
- nota geral,
- limpeza,
- comunicação,
- check-in,
- localização,
- experiência.

### Também analisa:
- textos das avaliações;
- riqueza dos comentários;
- confiabilidade do anfitrião.

## 5. Popularidade

O algoritmo mede:
- cliques,
- conversões,
- reservas,
- interesse dos usuários.

# A Jornada do Algoritmo

## ETAPA 1 — VISIBILIDADE

Objetivo:
> aparecer na busca.

## ETAPA 2 — CLIQUE

Objetivo:
> fazer o hóspede entrar no anúncio.

## ETAPA 3 — CONVERSÃO

Objetivo:
> transformar visualização em reserva.

## ETAPA 4 — EXPERIÊNCIA

Objetivo:
> gerar avaliações positivas.

# 📊 Todos os Impactos Mencionados

| Estratégia | Impacto mencionado |
|---|---|
| Reduzir estadia mínima | Até 18% mais reservas |
| Reserva instantânea | Até 10% mais reservas |
| Self check-in | Até 13% mais reservas |
| Descontos semanais/mensais | Até 5% mais noites reservadas |
| Calendário aberto | Mais visibilidade |
| Muitas fotos | Maior conversão |
| Fotos acima de 30 | Mais chance de ser Preferido dos Hóspedes |
| Comentários detalhados | Mais confiança |
| Preço com desconto riscado | Mais cliques |
| Popularidade alta | Melhor posicionamento |
| Reviews positivos | Mais reservas |
| Respostas rápidas | Melhor experiência |
| Descrição forte | Melhor conversão |

# Conclusão

O algoritmo do Airbnb favorece:
- flexibilidade,
- experiência,
- conversão,
- qualidade,
- confiabilidade.

Quanto melhor o anúncio trabalha junto com o algoritmo:
- maior a visibilidade,
- maior a ocupação,
- maior o faturamento.
